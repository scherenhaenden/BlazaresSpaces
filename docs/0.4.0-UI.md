# 0.4.0 UI direction

The normal surface has two explicit levels: Overview (all windows, displays,
management status and native placement) and a selected Virtual Space (windows
grouped by physical display). Assignment controls state their target explicitly:
`Window → Virtual Space` or `Window → Screen in Virtual Space`.

Native topology is an advanced diagnostic view. It is never the primary mental
model and never exposes destructive operations without ownership and confirmation.
