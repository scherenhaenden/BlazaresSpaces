# 0.4.0 test plan

Automated tests use synthetic topology values and must cover normalization,
mapping reconstruction, missing/disconnected displays, reordered Spaces,
fullscreen filtering, stale IDs, conservative reconciliation, partial global
activation, capability loss, and preservation of logical membership/NEVER MANAGE
behavior. No test mutates Mission Control.

Manual Mac validation is separate: enumerate on each supported macOS release,
focus with one and multiple displays, hotplug/sleep recovery, fullscreen behavior,
WindowServer restart, and accessibility/event permissions. Destructive tests may
only use an explicitly labelled Space created by the developer test harness.
