# 0.4.0 Native Spaces research

Status: implementation guidance, not a guarantee of private ABI stability.

## Findings

| Primitive | Evidence | Decision |
| --- | --- | --- |
| Enumerate displays and Spaces | `SLSCopyManagedDisplaySpaces` returns display dictionaries containing `Display Identifier`, `Current Space`, and `Spaces`; entries commonly contain `id64`, `uuid`, `type` | Adopt read-only dynamic lookup in `SkyLightNativeSpacesProvider`; reject malformed shapes. |
| Stable identity | Space UUIDs are more durable than `id64`; the first desktop may have an empty/missing UUID | Prefer UUID plus display identity. Runtime ID is same-session fallback only. |
| Classify Spaces | Research implementations distinguish user, fullscreen, tiled and system/unknown entries | Only `.userDesktop` participates in conservative positional mappings. |
| Focus | Existing tools use Dock/CGEvent gestures or private SkyLight calls | Keep experimental gesture focus capability-gated and verify each transition by rereading topology. |
| Move windows | Research identifies `SLSBridgedMoveWindowsToManagedSpaceOperation` and related private calls | Do not enable until ABI, ownership and window revalidation are proven. Current capability is unavailable. |
| Create/destroy | Hammerspoon research uses Dock accessibility for creation/removal; it is UI automation, not a stable public contract | Leave both unavailable. Never destroy an unowned or fullscreen Space. |

## Reference implementations inspected

- [yabai `space_manager.c`](https://github.com/asmvik/yabai/blob/master/src/space_manager.c) — current source showing managed-space enumeration and private move-operation lookup. GPL project; no code copied.
- [spacekit macOS Spaces research](https://github.com/cehbz/spacekit/blob/main/macos-spaces-research.md) — UUID versus `id64`, display mappings, fullscreen/tiled caveats, and Tahoe-era reliability notes.
- [Hammerspoon undocumented Spaces](https://github.com/asmagill/hs._asm.undocumented.spaces) — historical type masks, user-space filtering, move semantics, and explicit warnings about OS-version breakage.
- [CGSInternal](https://github.com/NUIKit/CGSInternal) — historical declarations used as API-name research only.

## Reliability and operational constraints

Private SkyLight symbols are dynamically resolved. Missing symbols, null results,
unexpected dictionary shapes, duplicate IDs, display hotplugging, fullscreen
entries, and WindowServer restarts are treated as unavailable/degraded states.
`NSScreen.screensHaveSeparateSpaces` changes whether a complete cross-display
binding can be inferred. Positional correspondence is a planning aid, never a
durable identity.

The backend does not disable SIP or require a scripting addition. Some reference
tools do require scripting additions, accessibility permission, or a privileged
yabai configuration; those requirements are not acceptable hidden prerequisites
for the application. Real-Mac validation remains mandatory on each supported
macOS release.

## Adopted boundary

The Domain layer sees only value types and reconciliation decisions. SkyLight,
CGS, Dock gestures, dynamic symbols, and WindowServer behavior remain inside
`Infrastructure/NativeSpaces`. Discovery is available independently from create,
destroy, focus, and move capabilities.
