# 0.4.0 implementation status

Terminology is strict: **Virtual Space** means the BlazaresSpaces global user-facing context; **Native Space** means a macOS Mission Control Space; **Screen/Display** means a physical monitor. UI strings referring to BlazaresSpaces contexts must not call them Desktops.

## Implemented foundation

- read-only SkyLight topology discovery via dynamically resolved `SLSMainConnectionID` and `SLSCopyManagedDisplaySpaces`
- display/current-Space/UUID/id64/type parsing and validation
- Separate Spaces-aware global bindings, including partial bindings
- conservative durable native identity and mapping persistence
- reconciliation planning with retain/create/review and no destructive action
- experimental verified Dock-gesture focus backend
- global activation failure reporting
- screen placement domain model and persistence
- Overview/Virtual Space assignment UI foundation

## Native mutation status

- native Space creation: **PARTIAL** — dynamic `CGSSpaceCreate` path with fresh-topology delta verification; display attachment depends on Dock behavior and is rejected if ambiguous.
- native Space destruction: **PARTIAL** — dynamic `CGSSpaceDestroy` path with explicit ownership, UUID/runtime identity, current/last-Space guards, and removal verification.
- moving a managed window: **PARTIAL** — Tahoe bridged operation plus legacy fallback, conservative CGWindowID resolution, async membership verification; runtime support is version-dependent.
- `ensure required Spaces` reconciliation: **COMPLETE** as an executable, serialized planner/executor with refresh-after-each-mutation and partial/degraded results.
- global activation: **PARTIAL/EXPERIMENTAL** via verified Dock gestures; direct SkyLight focus is not assumed.

Capabilities are detected at runtime and must not be interpreted as proof that a particular macOS release will accept every mutation.

## Safety rule

Every native mutation must be preceded by a fresh topology read and identity validation. Final success must be verified against a newly read topology and newly calculated bindings, never only against a pre-operation snapshot.
