# 0.4.0 Native Spaces architecture

Virtual Spaces remain the product abstraction: one global context spanning all
connected displays. Native Spaces are infrastructure resources mapped to that
context, not user-facing desktop identities.

```text
SwiftUI / menu bar
        ↓ explicit intent
WorkspaceApplicationService (@MainActor, serialized)
        ↓ ports
Domain: Virtual Spaces, membership, reconciliation plan
        ↓
Infrastructure/NativeSpaces: SkyLight discovery, gesture focus, capability checks
Infrastructure/Persistence: durable Virtual ↔ native mapping records
```

## Contracts

`NativeSpacesProviding` is read-only. `NativeSpacesControlling` exposes the
existing global activation plus capabilities and conservative create/destroy/
focus/move hooks. Default operations report unavailable, so a missing private
API cannot disable the logical backend.

`NativeSpaceIdentity` prefers `(displayIdentifier, uuid)`. `runtimeID` is retained
only for same-session lookup. `NativeSpaceMappingStore` persists these mapping
records separately from window state and validates duplicate keys atomically. A
mapping recovery that cannot uniquely resolve a Space produces review/degraded
state; it never guesses from index alone.

## Reconciliation

The pure `NativeTopologyReconciler` performs: topology read, mapping recovery,
missing-resource calculation, and plan generation. Existing Spaces are retained
only when a durable identity matches. A positional existing Space requires
explicit review. Missing resources may produce create actions. No action destroys
a Space; destruction is separately ownership-gated and currently unavailable.

## Switching

Activation is one serialized global operation. Each display is independently
targeted and verified. If any display fails, the result is failure/degraded and
the logical active workspace is not advanced as if the global operation had
succeeded. The logical parking/restoration backend remains available as fallback.

## Compatibility policy

Private API use is isolated, dynamically resolved, and capability-gated. A
macOS update may reduce native capabilities to discovery-only. The app must still
launch and retain logical Virtual Space behavior.
